# CineMatch

Sistema di raccomandazione cinematografica (Progetto SAPD, Gruppo 27).

## Struttura

- `core/`: Core Service (backend per il frontend, interfaccia web, autenticazione, watchlist, locandine da TMDB)
- `ai-service/`: AI Recommendation Service (embedding in RAM, strategie di raccomandazione)
